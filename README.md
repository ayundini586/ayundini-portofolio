# Ayundini Nursyahrin Portfolio

Static portfolio website for Ayundini Nursyahrin.

## Deploy to Vercel

1. Create a new GitHub repository and upload this folder.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the default settings: this is a static HTML website with `index.html` at the repository root.
4. Select **Deploy**.

Future content management can use Supabase. Project data is currently centralized in `projects.js`, making the later migration straightforward.
